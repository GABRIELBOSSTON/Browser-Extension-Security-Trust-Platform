# Research Directory — Antigraviiti Extension Protect (AEP)

This directory contains primary domain, threat intelligence, and vulnerability research supporting the architectural decisions of AEP.

## Subdirectories

- `browser_security/` — Sandbox models, process isolation, renderer boundaries.
- `extension_security/` — Manifest V2 vs V3 security models, CSP headers, content script DOM access.
- `cve/` — Known JavaScript library vulnerabilities (jQuery, Lodash, Crypto-js).
- `malware_extensions/` — Case studies of malicious browser extensions (e.g., WhatsApp Web data exfiltration).
- `threat_intelligence/` — Malicious domain blocklists, VirusTotal API integration schemas, IOC formats.
- `browser_api/` — Risks associated with elevated Chrome/Edge APIs (`webRequest`, `cookies`, `management`, `debugger`).
- `chrome_architecture/` — Chromium multi-process model & extension service worker lifecycle.
- `competitor/` — Competitive analysis of commercial and open-source extension scanners.
- `papers/` — Academic research papers & whitepapers on extension security.
- `case_studies/` — Real-world browser extension breach reports.
